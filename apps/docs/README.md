# AgileFlow documentation site

The v5 documentation at https://docs.agileflow.projectquestorg.com, built with Next.js and Fumadocs.

```bash
npm run dev      # http://localhost:3002
npm run build
npm run test:e2e
```

## Content

Pages live in `content/docs/` (MDX) with navigation in each folder's `meta.json`:

| Folder | Pages |
| --- | --- |
| `/` | Introduction, installation, quick start |
| `commands/` | `init`, `add`/`remove`/`list`, `sync` vs `update`, `check`, `configure`, `fork`/`diff`, `migrate`, `eval` |
| `concepts/` | Skills and packs, skill sources, project and personal skills, providers |
| `guides/` | Updates and conflicts, customizing skills, migrating from v4 |
| `reference/` | Official skills and packs, `agileflow.yaml`, `agileflow.lock` |

Write only about implemented v5 behavior, and state provider verification exactly as tested. v4 documentation is not part of this site; it lives on the `v4` branch.

## Brand

Achromatic: silver `#BFC3C9` on near-black `#09090B`, no accent color. Logos, icons, and `og.png` in `public/` are generated by `assets/brand/generate.py` at the repository root; see `assets/brand/README.md`.
